Интерактивная карта "SIGHT".<br />
Это некоммерческий проект на бесплатном хостинге Github Pages. Я создал его в свободное время для своего <a href="https://hh.ru/resume/8bbb00a0ff0fe0c1af0039ed1f57476e457858">резюме</a>.<br />
Если кому пригодится – пользуйтесь на здоровье, но чур не забудьте поставить "звездочку". А лучше дайте мне работу ^-^<br />
<br />
Текущие возможности проекта:

<ul>
<li>Карта мира (OSM) в трех проекциях на выбор: 3D, 2D и перспектива ("Columbus view", 2.5D);</li>
<li>Расчет географических координат под курсором мыши;</li>
<li>Выбор системы координат ("WGS-84", "СК-42 м", "СК-42 °", "ПЗ-90.11");</li>
<li>Нанесение на карту меток и простых геометрических фигур с возможностями их экспорта в табличный .ods-документ и последующего импорта;</li>
<li>Экспорт / импорт векторных объектов формата .kml (.kmz)</li>
<li>Линейные и площадные измерения на карте;</li>
<li>Полное управления камерой;</li>
<li>Управление темами оформления (светлая/темная, плюс четыре цветовые палитры);</li>
<li>Полноэкранный режим;</li>
<li>Снимок экрана (без интерфейса);</li>
<li>Поддержка мобильных устройств (тачпад).</li>
</ul>
Также, если у меня будет время, я планирую добавить: поиск, навигацию, локализацию (L10n (eng)), загрузку и визуализацию пользовательских растровых, векторных и 3D-изображений.<br />
